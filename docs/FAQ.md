# 常见问题

面向 Windows 便携版用户。当前正式版本为 v1.0.1，增加厂商语法底色，保留“中文目标 + 模拟命令行”学习流程与按需审计；旧版继续保留。文件、校验值与实测范围见 [下载与交付记录](../DELIVERY.md)。

## 如何下载并开始使用？

使用有访问权限的 GitHub 账号登录，点击 [v1.0.1 单 EXE](https://github.com/klwb360/NetConfig-Auditor/releases/download/v1.0.1/NetAudit-1.0.1-windows-x64-fb5a64016f45-onefile.exe)，下载后双击即可打开本地网页。需要配套资料时下载 [便携 ZIP](https://github.com/klwb360/NetConfig-Auditor/releases/download/v1.0.1/NetAudit-1.0.1-windows-x64-fb5a64016f45-portable.zip)，解压一次，进入文件夹双击 `Start-NetAudit.bat` 或 `NetAudit.exe`；不要在 ZIP 预览窗口内运行。网页默认进入配置练习，按下面步骤载入备份；也可切到“按需审查”直接审计原始备份。

普通使用无需下载 GitHub 自动生成的 “Source code”。两个运行 ZIP 内的 `*-source-*.zip` 是分发所对应的完整源码，供查阅、修改与重建；Release 已移除重复的独立源码附件，版本标签仍固定到构建提交。

## 各种底色是什么意思？

Cisco 蓝、华为橙、H3C 紫、锐捷绿；共享语法显示候选厂商，未知行保持中性。底色只表示语法归属，不代表安全、可执行或真实设备支持。

原始备份与模拟命令区会按已识别的厂商语法显示底色，配有文字图例与光标行说明。自动模式下共享语法保持中性；指定兼容厂商时显示该厂商底色并注明“上下文 / 共享语法”。其他厂商的明确语法仍显示自身颜色，普通注释、Banner 正文与无法确认的行保持中性。长命令可横向滚动，编辑、选择、复制和导出保留原文；颜色不会写入配置或报告，也不改变模拟及审计判断。

## 如何开始一次配置练习？

1. 导入备份或“载入示例”，核对厂商，点击“载入模拟”。左侧原始备份保留，右侧建立独立副本。
2. 输入一个中文目标，例如 `创建 VLAN 20`，点击“生成命令草案”，阅读每步理由，再“将草案放入命令区”；也可直接输入设备命令，每行一条。
3. 点击“预览运行”，核对每条命令的状态、原因与配置差异。预览成功也不会自动应用。
4. 点击“应用本次预览”，才改变当前练习副本。需要时“撤销上一步”“重置为原始备份”或“导出模拟配置 .cfg”。
5. 练习后可点击“审查当前模拟配置”，查看原有审计并导出报告；也可以直接结束练习。

未应用的预览不参与导出或审计。一批命令中任何一条失败，整批配置和命令行视图都会回滚；修正原因后重新预览。详细范围见 [模拟练习说明](../network-config-auditor/docs/SIMULATOR.md)。

## “可修改”“当前不能运行”和“尚不支持”有什么区别？

| 提示 | 意思与下一步 |
|---|---|
| 可修改 | 工具已实现该语法，当前视图和配置前提满足；阅读差异后决定是否应用到副本。 |
| 当前不能运行 | 当前配置缺少前提，例如 VLAN 尚未创建、接口模式不符或仍有依赖；按给出的原因补齐后再试。 |
| 尚不支持 | 本版没有实现该语法，不能推断真实设备不允许运行；需要查设备手册或使用其他实验环境。 |
| 参数不合法 | 命令中的地址、编号或格式无效；按提示改正。 |

这是离线配置状态练习，不是完整设备操作系统；不模拟 ping、数据包转发、物理链路、STP 收敛或 OSPF 邻居。“可修改”也不保证固件兼容、登录成功或业务连通。

## 中文目标是 AI 吗，为什么有时要补充信息？

中文草案是离线规则模板，不调用模型、不联网。它支持明确的单一目标，例如 `创建 VLAN 20`、`把接口 GigabitEthernet0/1 加入 VLAN 20`、`关闭 HTTP`。接口必须使用备份中的完整名称；要配置地址或路由时需提供掩码与下一跳等必要参数。

多个动作、附加条件、否定句或缺少参数时，工具会提示拆开或补充，不会仅执行其中理解的一部分。生成草案后还会通过同一模拟器检查，仍需先预览、再明确应用。它与审计页中可选的本机 AI 解释是两个功能；本版不生成账号、密码或密钥修改草案。

## 练习会改掉备份吗？关闭后能恢复吗？

不会覆盖原始文件或左侧备份。应用只改变练习副本，保留未改动原文与未识别配置；可以撤销最多 20 步，历史总量不超过 16 MiB，超额时移除最早历史。重置恢复载入时备份和执行视图，并清除历史。

练习仅保存在当前页面内存中，刷新、关闭页面、重新导入或更改原始输入会结束练习。需要留存时点击“导出模拟配置 .cfg”；该文件只包含已经应用的配置，不含未应用预览，且保留原始凭据，应按敏感备份保存。它不是脱敏审计报告。

## 审计检查的是备份还是模拟结果？

建立模拟副本后，“开始审计”和“审查当前模拟配置”都检查当前已应用副本。没有载入模拟时，“开始审计”检查左侧原始备份。单纯切换“按需审查”不会自动审计；配置变更后旧结果与导出失效，需要重新运行。模拟不会自动调用 CVE / KEV 或 AI。

## 为什么 Release 只剩三个运行附件？

v1.0.1、v1.0.0、v0.2.3、v0.2.2、v0.2.1、v0.2.0、v0.1.0 均提供 `portable.zip`、`onefile.zip` 和 `onefile.exe`，运行文件与原版本标签不变。校验文件 `SHA256SUMS.txt`、构建清单 `manifest.json` 和三份 `smoke-*.json` 验收报告永久保存在仓库 [发布档案](releases/README.md)，可按版本查看。原校验文件仍覆盖完整九文件构建产物，其中独立源码 ZIP 可从运行 ZIP 内取得。GitHub 自动生成的 “Source code” ZIP/tar.gz 无法单独隐藏。

## 如何切换暗黑风格？

在网页顶部的主题选项选择“暗黑风格”，也可选择“明亮风格”或“跟随系统”。默认跟随系统，浏览器仅记住主题偏好，不保存配置。主题偏好属于当前浏览器的站点数据；端口变化或清除网站数据后可能需重新选择，浏览器禁用存储时仍可切换当前页面的主题。

## 重复风险为什么折叠起来，报告会少内容吗？

规则、严重度、分类、确认程度与标题相同的发现集中展示，显示项数与涉及处数；重复项目默认折叠，单项单处直接显示。点击项目，或使用“展开全部”，即可核对每项对象、证据和建议；不同 VLAN 保留各自命令。折叠只改变网页显示，审计统计与三种完整报告不减少；原有后端同类风险合并继续保留。

## 新版网页如何查看结果？

先选择要审计的当前配置并开始审计，再切换安全发现、网络架构、漏洞情报、AI 建议、报告与清单、使用帮助六个页签；窄屏按顺序堆叠配置与结果。严重度筛选和页签切换不会减少完整导出的内容。修改配置、厂商或情报/模型设置后，旧结果与导出会失效，需要重新审计；高级设置只在需要设备版本核对或本机 AI 时填写。

分步操作介绍见 [新版网页怎么用](../README.md#新版网页怎么用)。

## 为什么有的下载包需要解压两次？

从 Release 下载的便携 ZIP 只需解压一次。开发或备份使用的 [Windows Actions 产物](https://github.com/klwb360/NetConfig-Auditor/actions/workflows/netaudit-windows.yml) 有外层 ZIP，需先解压外层，再解压其中的 `portable.zip`，才能找到 EXE。Actions 产物有保留期限；Release 下载仍需要私人仓库访问权限。

## portable 和 onefile 有什么区别？

| 版本 | 如何使用 |
|---|---|
| `portable.zip` | 推荐。解压后保留整个文件夹；`NetAudit.exe` 依赖同目录的 `_internal`，不能只复制 EXE。 |
| `onefile.zip` / `onefile.exe` | EXE 内含运行库，启动时会解压到用户临时目录，首次启动可能多等几秒。ZIP 还提供说明、示例、许可证和对应源码。 |

单 EXE 可以独立运行；再次分发时请同时提供许可证、归属说明与对应源码。源码 ZIP 用于查阅、修改和重建，普通使用无需解压源码。

## 需要安装 Python 或使用管理员权限吗？

便携 EXE 自带 Python 运行库；源码版 BAT 需要 Python 3.10 或更新版本。普通使用设计为无需管理员权限，报告请选择自己有写入权限的位置。

各版本的实际环境与结果见 [交付记录](../DELIVERY.md)，不能用源码测试或旧版测试推定新版 EXE 已验收。历史 v0.2.3 在 Windows Server 2022 x64 完成 272 项应用测试与 28 项真实进程验收，Linux Chromium 112 项主题、风险折叠与拖入 / 导出检查通过。Windows 10/11、ARM64、普通非管理员账户、物理上未安装 Python 的独立电脑及 Windows 人工浏览器交互仍需单独验证。

## 配置文件如何准备，支持哪些设备？

一次导入一台设备的完整 UTF-8 配置。可拖入网页左侧配置文本区域，或点击导入按钮；支持无扩展名、中文和空格文件名，最大 2 MiB / 30000 行。文件夹和多个文件会给出提示。识别不明确时手动选择厂商，再选择“载入模拟”或“开始审计”。Cisco / 锐捷使用 `show running-config`，华为/H3C 使用 `display current-configuration`；导出时去掉分页符、终端提示符和颜色控制字符。

支持 Cisco IOS/IOS XE、Huawei VRP、H3C Comware 和锐捷 RGOS 已建模的常见 IPv4 配置。华为和 H3C 共享不少语法，不能自动识别时请明确选择厂商。Cisco ASA/NX-OS、IPv6、复杂策略与完整动态路由语义等尚未完整建模，具体范围见 [项目说明](../network-config-auditor/README.md#支持范围)。

v0.2.2 已提供锐捷 RGOS 已建模语法；有明确 `version ...RGOS` 标记时自动识别，否则手动选择“锐捷 RGOS”或使用 `--vendor ruijie`。旧版 v0.2.1 Windows 包不包含这项支持。

## 为什么多个端口都提示 VLAN 未定义？

端口引用同一 VLAN 时，旧版可能逐端口重复提示；如果原始配置使用解析器尚未支持的 VLAN 范围声明，也可能遗漏定义。v0.2.2 补充已支持的 RGOS VLAN 范围语法，并按 VLAN ID 合并为一项发现，保留全部关联端口与行号；不同 VLAN 仍分别报告。

“输入未见 VLAN 定义”只表示需要核对，不证明设备未创建。先取得完整配置，并在 Cisco / 锐捷执行 `show version`、`show vlan`，华为 / H3C 执行 `display version`、`display vlan`；确认 VLAN 数据库和动态来源，再重新导入配置审计。只有确认缺失、VLAN ID 与业务规划正确时才考虑报告中的创建建议，避免把解析不足当成真实故障。

## 建议命令能直接复制执行吗？

v0.2.2 把建议分为只读核查、参数已知的候选整改脚本和需填参数的模板，并列出适用前提。先用只读命令核查设备版本与现状，再确认业务和管理回退路径；模板中的 `<参数名>` 必须替换。工具不会猜测地址、密钥或业务 ACL，也不会连接设备、执行命令或自动保存配置。合并后的发现仍保留每个对象的完整脚本和证据。

## 没有发现问题，是否说明配置安全？

审计仅覆盖当前解析能力和规则。`confirmed-config` 表示有配置证据，`needs-review` 表示需结合设备版本、拓扑或业务人工核对；未建模配置行也需检查。严重度筛选仅调整网页中展示的发现，完整报告仍用于整体复核。工具不会连接设备或下发建议命令。

## 六个架构领域的状态是什么意思？

VLAN、STP、OSPF、ACL、NAT、Management Plane 分别列出已观察到的配置、覆盖说明和相关规则。`checked` 表示已检查观察到的受支持内容；`needs-review` 表示有发现或相关未建模语法；`not-observed` 表示输入未观察到该领域。任何状态都不能证明实时拓扑、邻居或整个网络已安全。

STP 未写启停命令时保持未知，OSPF Network 是接口选择条件；工具不会将配置推断成当前根桥、邻居或实际路由状态。

## CVE / KEV 是否会自动联网，是否能确认设备已被入侵？

默认读取随包的 CISA 官方 KEV 离线快照，不联网。快照日期和来源可在报告中查看；它不是实时、完整的漏洞库。用户显式运行 `intel-update` 才下载官方 KEV，且不上传配置或设备信息。更新后的文件需通过 `--kev-file` 或网页本地导入使用。

KEV 表示相关漏洞在现实中已有利用记录，不表示当前设备受影响或已被入侵。需要精确产品 CPE、明确版本和本地 NVD CVE 2.0 数据才能核对适用性；未知版本、仅输入 CVE 编号或复杂条件保持待核对候选。没有匹配项不能证明不存在漏洞。格式和示例见 [情报说明](../network-config-auditor/docs/INTELLIGENCE.md)。

## AI 是否必须安装，会把配置发到云端吗？

AI 是可选解释功能。默认关闭，没有本机模型也能完成配置审计与报告导出。当前只支持本机 Ollama：自行安装、启动 Ollama 并准备模型后，在网页明确启用并填写模型名，或 CLI 使用 `--ai-model`。地址仅允许本机回环地址，不能配置远程云端服务。

规则自带的风险与建议来自确定性审计，不称作 AI 输出。AI 解释不能新增已确认漏洞、改变规则严重度或替代人工复核；请求失败会在报告标记原因，并保留规则和情报结果。实际发送字段、模型输出和本机模型验收范围见 [AI 说明](../network-config-auditor/docs/AI.md)。

## 配置会上传到哪里，报告如何保存？

配置在本机处理，网页只访问本机 `127.0.0.1`，上传内容和练习历史不会持久保存到程序目录。显式开启 AI 后才调用本机模型，显式更新 KEV 才访问官方数据源。点击“导出模拟配置 .cfg”保存当前副本，或审计后点击 JSON、Markdown、HTML 保存报告；文件下载位置由浏览器决定。配置文件保留原始凭据，报告则对常见凭据脱敏。

报告包含设备名、地址和网络结构；常见凭据会脱敏，但不能保证识别所有敏感字段。请按内部配置资料保护，公开反馈问题时使用合成或人工脱敏的样例。

## 如何关闭，如何迁移到另一台电脑？

回到启动的命令行窗口按 Ctrl+C。关闭浏览器标签页不会停止服务。下次运行请使用启动窗口显示的地址；端口被占用时地址可能变化。

迁移便携版时复制整个解压文件夹，包括 `_internal`；用户自行保存的配置和报告也需另外复制。程序文件夹可以位于只读位置，运行所需临时数据使用用户临时目录，导出位置仍需可写。

## 能否只用命令行，不打开浏览器？

可以。在便携文件夹中打开命令提示符：

```bat
Start-NetAudit.bat serve --no-browser
NetAudit.exe plan "D:\网络配置\设备.cfg" --vendor huawei --goal "创建 VLAN 20"
NetAudit.exe simulate "D:\网络配置\设备.cfg" --vendor huawei --commands "D:\练习\commands.txt" --out "D:\练习\模拟配置.cfg"
NetAudit.exe audit "D:\网络配置\设备.cfg" --vendor huawei --format html --out "D:\审计报告\设备.html"
```

传入参数时 BAT 不会暂停。`plan` / `simulate` 需 v1.0.0；标准输出是 JSON，模拟 JSON 的 `config` 保留原始凭据。命令批次失败返回 2、整批回滚且不写 `--out`。三种审计报告格式参数为 `json`、`md`、`html`；完整用法见 [项目说明](../network-config-auditor/README.md#最快开始)。遇到问题请看 [故障排查](TROUBLESHOOTING.md)。
