01
开始使用
导入 UTF-8 配置或粘贴完整配置文本，选择厂商后点击「开始审计」。不确定厂商时保留自动识别；「载入示例」可快速体验。

            
02
查看与导出
从安全发现开始，逐项核对行号、证据和建议。网络架构与漏洞情报提供补充依据；用顶部按钮导出 Markdown、HTML 或 JSON 完整报告。

            
03
关闭程序与迁移
回到启动窗口按 Ctrl+C。关闭浏览器标签页不会停止服务。迁移到另一台 Windows 电脑时，复制整个便携文件夹，再双击启动。

            
04
设备版本与情报
KEV 使用随包快照，支持导入新的官方 JSON。精确漏洞匹配还需要实际设备版本 CPE 和 NVD JSON；手工 CVE 编号只作为候选项。工具不自动下载情报。

            
05
可选本机 AI
先安装 Ollama 和模型，再在左侧启用。只发送结构化规则与情报事实，不发送原始配置；单次请求最多等待 30 秒。模型建议需经过证据与业务验证。

            
06
本地处理与审计范围
配置与情报处理在本机运行，普通使用无需管理员权限。检查依据来自输入配置；实际影响仍需结合设备版本、拓扑和运行状态核对。
