# 校园网配置独立金标准 v1.1

50 份人工合成配置：Cisco 18、Huawei 16、H3C 16；25 个风险规则各有应报/不应报实例。CLI 语法来源于已支持厂商命令形式，数据不是设备采集配置，未连接或实测任何设备。

- `configs/`：可直接交给离线审计的 UTF-8 配置片段。
- `expected/`：逐例人工指定的库存、风险、未知结论、不应报规则和需保留原文的未知命令。
- `manifest.json`：来源、场景、固定支持字段路径、未知语义和资产 SHA256。
- `author_fixtures.py`：独立编写记录，逐场景显式写配置及金标准，未导入当前解析/规则代码；验收不会运行它。

在 `network-config-auditor` 运行 `python tools/benchmark_acceptance.py --out reports/acceptance.json`。该命令只测量，不修复标注。不要把程序输出复制回 expected。失败时先检查配置原意和支持边界；真正的标注错误需独立复核、解释变更原因并升级数据集版本。

范围、公式、阈值及局限见 [验收说明](../../docs/ACCEPTANCE.md)。源码回归测试和这组有限金标准承担不同验证职责，二者都通过仍不证明真实设备转发或完整合规。

v1.1 按 H3C 官方语法修正 NAT 控制例的撤销输入，独立 `nat=[]` 预期不变；先确认旧解析实现因此验收失败，再修复实现。官方来源、旧哈希及 Huawei 命令族差异见 [变更记录](CHANGELOG.md)。
