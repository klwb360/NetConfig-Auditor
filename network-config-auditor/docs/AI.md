# 可选本机 AI 解释

NetAudit 默认关闭 AI。配置解析、架构检查、规则审计、离线 CVE / KEV 情报关联和 JSON / Markdown / HTML 导出都能独立运行。

启用 AI 后，工具调用本机 Ollama，为已有发现生成中文解释与人工整改顺序。AI 不能改变原有严重度、规则标识或置信度，也不会运行建议命令。生成失败会明确显示“AI 未完成”，保留规则报告；没有发现时跳过模型调用。

## 启用方法

1. 按 [Ollama 官方说明](https://docs.ollama.com/)安装并启动 Ollama。
2. 自行准备适合电脑内存的**本地模型**，确认模型已安装。本工具不自动安装 Ollama、不下载模型。
3. 在网页的 AI 设置中显式启用，并填写模型名称；或在 CLI 指定 `--ai-model`。

```console
python -m netaudit audit examples/cisco.cfg --vendor cisco --ai-model qwen2.5:7b --format md --out report.md
NetAudit.exe audit examples\cisco.cfg --vendor cisco --ai-model qwen2.5:7b --ai-timeout 60 --format html --out report.html
```

模型名称只是示例，工具不保证该模型已安装或该电脑有足够资源。CLI 不指定 `--ai-model` 时关闭 AI。可通过 `--ai-endpoint` 指定本机服务地址，默认 `http://127.0.0.1:11434`；`--ai-timeout` 为 1–120 秒，默认 30 秒。

便携 EXE 的审计功能不依赖 Python。可选 AI 仍需要电脑上运行 Ollama 和已安装的模型；复制 NetAudit 文件夹不会自动迁移 Ollama 或模型。

## 发送哪些数据

NetAudit 只向本机回环地址发送以下最小事实：

- 安全 / 架构发现：规则标识、标题、严重度、通用风险、通用整改建议。同一规则只发送一次。
- 情报条目：CVE 编号、匹配或候选状态、KEV 收录状态、置信度，以及 KEV 官方处置建议。

原始配置、设备名、实际设备型号 / 版本、配置行、证据、清单、凭据、建议命令和情报自由备注不进入请求。模型只能引用已提供的 CVE 编号；新增编号会使该次 AI 结果整体失败，不会出现在有效解释中。

候选 CVE 仍是待核实线索；版本条件匹配不证明设备实际受影响；KEV 收录不证明当前设备已被利用。AI 解释必须与原始规则及情报状态一起阅读，不能替代厂商公告或人工核对。

## 网络和输出边界

服务地址仅允许 `http://` 或 `https://` 的字面回环 IP / `localhost`，不能包含账号、查询参数、路径或片段。`localhost` 会转换为 `127.0.0.1`，不依赖 DNS。请求不会使用系统 HTTP 代理，也不会跟随重定向到其他地址。

工具拒绝带 `-cloud` 或 `cloud:` 标记的模型名称。仍应确认本机 Ollama 使用本地模型：本机服务可能经过用户自定义转发，NetAudit 无法证明其他程序不会联网。工具没有远程 AI API 配置或 API 密钥入口。

请求最多 64 KiB、64 条不同规则 / 情报事实；响应最多 256 KiB；解释 JSON 最多 16000 字符，每条解释与整改文本各最多 2000 字符。网络读取使用总截止时间；超时、模型未安装、输出不完整、未知规则或新增 CVE 都会明确标记失败。配置与情报文本作为不可信数据，模型输出仅作为文本展示和导出。

## 常见问题

- **无法连接本机 Ollama：** 确認服务已启动，地址及端口正确；普通审计仍可继续。
- **HTTP 404：** 检查模型名称和安装情况，并查看 Ollama 本机日志；NetAudit 不把服务错误正文保存到报告。
- **超时：** 选用较小的模型，先在 Ollama 中确认能完成生成，再调整 `--ai-timeout`。
- **输出不完整或新增 CVE：** 该次模型输出会被拒绝。保留规则报告，人工复核；不以模板伪装成功的 AI 生成。
- **需要关闭 AI：** 网页取消启用，或 CLI 移除 `--ai-model`。无需删除模型才能使用 NetAudit。

## 验证范围

自动测试使用真实本机 HTTP 服务模拟 Ollama 协议，验证数据最小化、关闭时不联网、代理隔离、禁止重定向、超时 / 响应限制、输出白名单及原始报告不变。这些测试证明 NetAudit 的请求与失败处理行为；实际模型质量、模型安装和真实 Ollama 推理需在用户环境另行验证。
